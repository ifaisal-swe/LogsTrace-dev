# Security policy

## Reporting a vulnerability

Please **don't open a public issue**. Email **security@logstrace.dev** (or use GitHub's private "Report a vulnerability") with:

- What the issue is and where (file, route).
- Steps to reproduce or a proof of concept.
- Impact you expect.

You'll get a reply within 3 working days. Please give us reasonable time to fix it before disclosing. We'll credit you unless you prefer otherwise.

## Scope

- This repository and the hosted service at logstrace.dev.
- Out of scope: denial of service by volume, social engineering, findings that need a compromised server or `.env`.

## Supported versions

Only the latest `main` gets security fixes. Self-hosters should update regularly (see [docs/SELF_HOSTING.md](docs/SELF_HOSTING.md#update)).
