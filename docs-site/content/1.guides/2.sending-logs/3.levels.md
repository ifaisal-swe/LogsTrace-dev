| Level | Use for | Also accepted |
|---|---|---|
| `debug` | Detail you only need while investigating | `trace`, `verbose`, `silly` |
| `info` | Normal events (default) | `information`, `notice`, `log` |
| `warn` | Something unusual that didn't fail | `warning` |
| `error` | A failed operation | `err`, `exception` |
| `fatal` | The process or service can't continue | `critical`, `crit`, `alert`, `emergency`, `emerg`, `panic` |

Matching ignores case, so `WARNING` and `Error` work.

## Numeric levels

Numbers follow the pino scale:

| Number | Level |
|---|---|
| < 30 | `debug` |
| 30–39 | `info` |
| 40–49 | `warn` |
| 50–59 | `error` |
| ≥ 60 | `fatal` |

An unknown level name rejects the request with `400`, so typos don't silently become `info`.
