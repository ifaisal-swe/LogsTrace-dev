Open a table to see its rows. Every column can be filtered, sorted and summarised.

## Filters

Up to 20 filters, all must match.

| Operator | Meaning |
|---|---|
| `eq` / `neq` | Equals / not equals |
| `contains` / `not_contains` | Text inside the value |
| `gt` `gte` `lt` `lte` | Number comparison |
| `between` | Between two numbers |
| `in` | One of a list |
| `empty` / `not_empty` | Value missing or present |

Example: payments that were `declined` and above `100`.

## Summary mode

Switch to **Summary** to turn rows into numbers:

- **Metrics** (up to 6): `count`, `sum`, `avg`, `min`, `max`, `count_distinct`.
- **Group by** up to 3 columns, for example `status` and `currency`.
- **Bucket** by minute, hour, day, week or month to get a chart over time.

Example: count and total `amount` per day where `status` is `captured`.

## Export

Click **Export CSV** to download rows or summaries (up to 10,000 rows). Cells that start with `=`, `+`, `-` or `@` get a leading `'` so spreadsheets don't run them as formulas.

## Share

The whole query is stored in the URL. Copy it, or save it as a [view](/guides/exploring/saved-views).
