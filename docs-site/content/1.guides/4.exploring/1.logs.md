**Logs** shows every message in the project as it arrives.

| Filter | What it does |
|---|---|
| Search | Text in the message |
| Channel | One channel |
| Level | One or more levels |
| Table | Only messages grouped into one table |
| **More filters** → Trace id | Every message with that `traceId` |
| **More filters** → Data fields | Exact matches on `data`, for example `user.id=42, plan=pro` |

- Click a message to expand it and see its level, table, `data`, trace and span.
- Filters live in the URL: copy the address to share exactly what you see.
- New messages appear live. While you scroll, they wait behind a **Show N new messages** button.
- Save the current filters as a [saved view](/guides/exploring/saved-views).

::note
Viewers see IPs, emails and tokens masked, and the search runs on the masked text. See [Masking](/guides/teams/masking).
::
