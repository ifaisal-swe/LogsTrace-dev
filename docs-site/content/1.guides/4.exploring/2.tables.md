**Tables** lists every message shape LogsTrace found, with a 24-hour sparkline and the first time it was seen.

## Name things

Open a table and rename it (`Payment captured`) and its columns (`payment_id`, `order_id`, `status`, `amount`). Your names are kept when the table changes later. Column types (number, ID, text) are colour-coded everywhere a value is shown.

## Organise

| Option | Effect |
|---|---|
| Description | Short note shown under the name (≤300 characters, no links) |
| Tags | Up to 10 labels, for example `billing`, `critical` |
| Pin | Keeps the table at the top |
| Hide | Removes it from the list. Hidden tables still receive and return data |

Sort by name, busiest or recently active, and filter by tag.

::tip
Renaming and organising needs the **member** role or above. See [Roles](/guides/teams/roles).
::
