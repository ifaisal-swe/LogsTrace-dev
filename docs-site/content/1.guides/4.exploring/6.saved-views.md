---
title: Saved views
description: Save a search or table query for the whole team.
navigation:
  icon: i-lucide-bookmark
---

Click **Save view** on **Logs** or on a table to store the current filters, grouping and sorting under a name.

- Views are shared with everyone in the project, including viewers.
- Members, admins and owners can create and delete views; viewers can open them.
- Up to 200 views per project.

::warning
A view stores filter values as typed, and every project member can read them. Don't save views that filter on secrets.
::
