Every project starts with a **Project overview** dashboard built from its tables. Add your own under **Dashboards** (up to 50 per project, 24 panels each).

## Panel types

| Type | Shows | Data from |
|---|---|---|
| Time series | A line over time | Message volume, or a metric from a table |
| Stat | One number | Message volume, or a metric from a table |
| Bars | Top values | Volume split by level, channel or table, or a table grouped by a column |
| Table | A summary table | A table query |
| Logs | Latest matching messages | A logs search (text, channel, level, table) |

Each panel has a width (3, 4, 6, 8 or 12 of 12 columns) and a height (S, M, L).

## Range and refresh

All panels share the dashboard's time range. Turn on **Auto-refresh** to keep it current on a wall screen.

::note
Panels read data through the same queries as the rest of the app, so viewers see masked values here too.
::
