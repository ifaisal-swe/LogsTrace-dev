**Search** takes one value, an order ID, user ID, email or request ID, and shows:

- Every **table** it appears in, with how often and when it was last seen.
- Every **message** containing it, with the matching column highlighted (`order_id`).

```text
10293
```

finds

```text
Order 10293 paid 49.90 USD by card
Payment 8812 for order 10293 captured 49.90 USD
Refund for order #10293 requested
Shipment [10293] handed to carrier
```

## How matching works

- Whole words only: `10293` doesn't match `102930`.
- Punctuation around the word is ignored, so `#10293`, `[10293]` and `10293,` all match.
- Scans the latest 10,000 matches. If there are more, the result says so.
- Narrow it with a time range or a single table.
