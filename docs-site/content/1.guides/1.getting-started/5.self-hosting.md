LogsTrace is open source under [AGPL-3.0](https://github.com/ifaisal-swe/LogsTrace/blob/main/LICENSE). You can use the hosted version at [logstrace.dev](https://logstrace.dev) or run it on your own server.

::note
Everything in these docs works the same on a self-hosted instance. Replace `https://logstrace.dev` with your own URL.
::

## Requirements

- A Linux server with 2 vCPU, 4 GB RAM and 40 GB SSD (more disk as log volume grows).
- Docker with Docker Compose v2, and Git.
- A domain with HTTPS.
- A [Resend](https://resend.com) account for sign-up codes, password resets and invites.

::steps{level="3"}
### Clone and configure

```bash
git clone https://github.com/ifaisal-swe/LogsTrace.git
cd LogsTrace
cp .env.example .env
```

In `.env`, set at least `POSTGRES_PASSWORD`, `CLICKHOUSE_PASSWORD`, `NUXT_SECRET_KEY` (random values, e.g. `openssl rand -hex 32`), `NUXT_APP_URL`, `NUXT_RESEND_API_KEY`, `NUXT_MAIL_FROM` and `NUXT_BOOTSTRAP_ADMIN_EMAIL`.

### Start

```bash
docker compose --profile app up -d --build
```

Postgres, ClickHouse and the app listen on `127.0.0.1` only. Database migrations run on startup.

### Add HTTPS

Put a reverse proxy in front of `127.0.0.1:3000`. With Caddy:

```text
logs.example.com {
  reverse_proxy 127.0.0.1:3000
}
```

### Create the admin account

Right after the first start, register with `NUXT_BOOTSTRAP_ADMIN_EMAIL` and verify the email. That account becomes the platform admin.
::

::tip
Updating is `git pull` followed by the same `docker compose` command. The full guide, with backups, the production checklist and troubleshooting, is in [docs/SELF_HOSTING.md](https://github.com/ifaisal-swe/LogsTrace/blob/main/docs/SELF_HOSTING.md).
::
