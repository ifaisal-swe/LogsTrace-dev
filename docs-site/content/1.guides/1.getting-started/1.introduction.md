LogsTrace takes the plain-text messages your systems already write and organises them for you. You send `Order 10293 paid 49.90 USD by card`; LogsTrace notices that thousands of messages share that shape and builds a **table** for it, with the order ID, amount, currency and method as **columns**.

No parsing rules, no schema, no agent to install. One HTTP endpoint.

## What you get

::card-group
  :::card{icon="i-lucide-table-2" title="Automatic tables" to="/guides/getting-started/core-concepts"}
  Send objects like `{ "event": "order.paid", "orderId": "10293" }` and each key becomes a column. Plain messages work too: repeated ones are grouped into tables and the words that change become columns.
  :::

  :::card{icon="i-lucide-search" title="Trace any value" to="/guides/exploring/search"}
  Search an ID once and see every table, channel and message it appears in.
  :::

  :::card{icon="i-lucide-chart-column" title="Filter and summarise" to="/guides/exploring/querying"}
  Filter on any column, count and total by any field, group by day or hour, export to CSV.
  :::

  :::card{icon="i-lucide-radio" title="Live" to="/guides/exploring/live"}
  New messages stream into the dashboard as they arrive.
  :::

  :::card{icon="i-lucide-eye-off" title="Masking built in" to="/guides/teams/masking"}
  IPs, emails and tokens are hidden from viewers on the server, including in search and filters.
  :::

  :::card{icon="i-lucide-users" title="Teams" to="/guides/teams/roles"}
  Organizations, projects and four roles: owner, admin, member and viewer.
  :::
::
