::steps{level="3"}
### Create an organization and a project

Sign in at [logstrace.dev](https://logstrace.dev/app), create an **organization** (your team or company) and a **project** inside it (one app or environment, for example `checkout-api` or `staging`).

Every project gets a starter **Project overview** dashboard.

### Create an API key

Open the project, go to **API keys** and create a key with access **Send logs**.

The key starts with `lgk_` and is shown **once**. Copy it into your app's secrets.

::warning
Treat the key like a password. LogsTrace only stores a hash of it, so a lost key can't be shown again: revoke it and create a new one.
::

### Send a log

::code-group
```bash [curl]
curl -X POST https://logstrace.dev/api/ingest \
  -H "Authorization: Bearer $LOGSTRACE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"channel":"orders","event":"order.paid","orderId":"10293","amount":49.90,"currency":"USD","method":"card"}'
```

```js [Node.js]
await fetch('https://logstrace.dev/api/ingest', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.LOGSTRACE_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ channel: 'orders', event: 'order.paid', orderId: '10293', amount: 49.90, currency: 'USD', method: 'card' })
})
```

```python [Python]
import os, requests

requests.post(
    "https://logstrace.dev/api/ingest",
    headers={"Authorization": f"Bearer {os.environ['LOGSTRACE_KEY']}"},
    json={"channel": "orders", "event": "order.paid", "orderId": "10293", "amount": 49.90, "currency": "USD", "method": "card"},
    timeout=5,
)
```
::

The response is `{ "accepted": 1, "status": "ok" }`. Each key becomes a column of the `order.paid` table. Plain messages work too: `{"channel":"orders","text":"Order 10293 paid 49.90 USD by card"}`.

### See it in the dashboard

Open **Logs**: the message is there, live. Send a few more with different numbers and open **Tables**: LogsTrace has grouped them into one table with a column for each changing value.
::
