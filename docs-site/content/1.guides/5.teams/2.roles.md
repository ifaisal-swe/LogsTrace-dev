| Permission | Viewer | Member | Admin | Owner |
|---|:-:|:-:|:-:|:-:|
| Read logs, tables, views, dashboards | ✓ | ✓ | ✓ | ✓ |
| See members | ✓ | ✓ | ✓ | ✓ |
| See IPs, emails and tokens unmasked | | | ✓ | ✓ |
| Name tables and columns, manage views and dashboards | | ✓ | ✓ | ✓ |
| Create and manage projects | | | ✓ | ✓ |
| Create and revoke API keys | | | ✓ | ✓ |
| Invite and manage members | | | ✓ | ✓ |
| Read the audit log | | | ✓ | ✓ |
| Rename the organization | | | ✓ | ✓ |
| Delete the organization | | | | ✓ |

- Admins can only change or remove members with a lower role. Owners can manage everyone.
- People outside an organization get "not found" for it, so organization names don't leak.

::tip
Give support and stakeholders the **viewer** role: they can investigate without seeing personal data.
::
