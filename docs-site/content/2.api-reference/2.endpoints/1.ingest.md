::badge
POST
::

`/api/ingest`

Requires a key with **Send logs** access.

## Headers

::field-group
  :::field{name="Authorization" type="string" required}
  `Bearer lgk_...`
  :::

  :::field{name="Content-Type" type="string" required}
  `application/json`
  :::

  :::field{name="X-LogsTrace-Channel" type="string"}
  Default channel for events that don't set one.
  :::
::

## Body

One event, an array of 1–500 events, or `{ "events": [...] }`. An event is either **structured** (recommended: no `text`/`embed`, every other key is a field and becomes a named column) or a **message** (`text`). See [Event format](/guides/sending-logs/events).

::field-group
  :::field{name="event" type="string"}
  Structured event name, ≤100 of `[A-Za-z0-9_.:-]`, e.g. `order.paid`. Optional.
  :::

  :::field{name="<any other key>" type="any"}
  Structured field. Becomes a column named after the key (nested objects → `a.b`) and is stored in `data`. ≤50 per event. On a message, extra keys only go to `data`.
  :::

  :::field{name="text" type="string"}
  Message, ≤16 KB. Leave it out for a structured event. Aliases: `message`, `msg`, `body`.
  :::

  :::field{name="channel" type="string"}
  ≤100 characters. Aliases: `service`, `resource`, `source`.
  :::

  :::field{name="level" type="string | number"}
  `debug` `info` `warn` `error` `fatal`, common aliases, or a pino number. Default `info`. Alias: `severity`, `severityText`.
  :::

  :::field{name="ts" type="string | number"}
  ISO 8601, Unix seconds or Unix ms. More than 7 days off → receive time. Aliases: `timestamp`, `time`, `@timestamp`.
  :::

  :::field{name="data" type="object"}
  Own JSON, ≤32 KB including structured fields. Aliases: `metadata`, `meta`, `attributes`.
  :::

  :::field{name="traceId" type="string"}
  ≤128 of `[A-Za-z0-9_.:-]`. Alias: `trace_id`.
  :::

  :::field{name="spanId" type="string"}
  Same format. Aliases: `span_id`, `parentId`, `parent_id`.
  :::

  :::field{name="embed" type="object"}
  `{ title?, description?, fields?: [{ name, value, inline? }] }`, ≤25 fields. Flattened into `text`.
  :::
::

## Example

::code-group
```bash [Request]
curl -X POST https://logstrace.dev/api/ingest \
  -H "Authorization: Bearer $LOGSTRACE_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "events": [
      { "channel": "payments", "event": "payment.captured", "paymentId": "8812", "orderId": "10293", "amount": 49.90, "currency": "USD" },
      { "channel": "payments", "level": "warn", "traceId": "req-7f3a9c",
        "text": "Payment 8813 for order 10294 declined 120.00 USD",
        "data": { "gateway": "stripe" } }
    ]
  }'
```

```json [200]
{ "accepted": 2, "status": "ok" }
```

```json [400]
{ "statusCode": 400, "statusMessage": "Invalid event. events.1: Each event needs fields (like { \"event\": \"user.signup\", \"id\": \"42\" }), text (or message), or an embed" }
```

```json [429]
{ "statusCode": 429, "statusMessage": "Too many attempts. Try again in 1 minute(s)." }
```
::

The whole batch is accepted or rejected together.
