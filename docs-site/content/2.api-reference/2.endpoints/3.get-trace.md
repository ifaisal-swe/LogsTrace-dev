::badge
GET
::

`/api/v1/logs/trace/:traceId`

Requires a key with **Read logs** access. Shares the 120 requests per minute limit with [Query logs](/api-reference/endpoints/query-logs).

Returns the messages with that [`traceId`](/guides/sending-logs/tracing), **oldest first**, up to 200. `truncated: true` means there were more.

::code-group
```bash [Request]
curl https://logstrace.dev/api/v1/logs/trace/req-7f3a9c \
  -H "Authorization: Bearer $LOGSTRACE_READ_KEY"
```

```json [200]
{
  "status": "ok",
  "masked": true,

    { "id": 302, "timestamp": "2026-10-06T09:12:00.240Z", "level": "warn", "body": "Payment 8813 for order 10294 declined 120.00 USD",
      "channel": "payments", "traceId": "req-7f3a9c", "spanId": "charge", "templateId": "…", "metadata": {} }
  ],
  "truncated": false
}
```
